# Odesocan Verifica

Modelo web de referencia de Odesocan Verifica, el servicio de verificación de afirmaciones públicas sobre derechos sociales en Canarias de la Fundación Canaria Observatorio de Derechos Sociales de Canarias (ODESOCAN).

El trabajo se desarrolla en la rama `propuesta/odesocan-verifica` y se incorpora a `main` mediante una pull request.
